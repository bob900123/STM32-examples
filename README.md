# STM32 Examples

STM32 微控制器習與實作範例，使用 STM32F103C8T6 與 Keil MDK ARM 開發。

## 範例列表

| 編號 | 專案 | 說明 |
|------|------|------|
| 00 | LED Blink | LED 循環閃爍 |
| 01 | LED Running Light | LED 依序點亮形成流水燈效果 |
| 02 | Button Toggle LED | 使用外部中斷控制 LED 的亮滅 |
| 03 | UART and LED | 使用 UART 控制 LED 開關 |
| 04 | I2C EEPROM | 使用 I2C 控制 EEPROM 寫入和讀取 |
| 05 | LED Blink 2 | 使用 SysTick Timer LED 產生時間基準，使 LED 有規律的循環閃爍 |
